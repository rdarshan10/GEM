Memory that follows through.

When a fact changes, GEM finds everything that was built on it, even four links away, and leaves the rest alone.

scroll

01

Every memory is built on others.

Your commute was worked out from where you live. The alarm from the commute. The coffee maker from the alarm. GEM keeps those links as it stores facts.

02

Then something changes.

“I moved to Mumbai.” Before it's stored, GEM checks it against similar facts. One conflicts directly, and is updated.

03

Ordinary memory stops there.

Same write, flat memory. The fact that conflicted is fixed. The four facts built on it are still served as true, and nothing about them looks wrong.

04

GEM follows the links.

The change runs down every derived-from link. Each fact is re-checked against this change: stale, rewritten, or unaffected, like your timezone. Mumbai is still IST.

05

Cheap judgment first.

Each hop is one batched question to Jev, a small model that answers with probabilities. The rings are its answers. The LLM is only called to write a correction or settle a doubt.

06

A write costs what it touches.

Six memories, one change: the launch slipped. Only that plan lights up, six links deep. Nothing else is read or rewritten.

Give your agent this memory.

An MCP server for Claude Code, Claude Desktop, Cursor and other clients, or a Python library. Every save reports what it changed further down.

# MCP server
pip install -e ".[mcp,embeddings,jev]"
claude mcp add gem -- python -m gem.mcp_server

# or the library
from gem import Memory
m = Memory()
home = m.add("I live in Bangalore").id
m.add("My commute is 45 minutes", derived_from=[home])
m.add("I moved to Mumbai").invalidated   # [commute]
